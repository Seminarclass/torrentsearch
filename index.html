How it works

Two deployment modes. Both run entirely on GitHub.

1

Self-hosted backend (recommended)

Run node server/index.js on any host. The frontend calls /api/search directly for live, fresh results. Free tier hosts that work: Railway, Render, fly.io.

2

GitHub Actions only

No backend needed. A scheduled workflow runs the scraper every hour, commits the latest results to data/latest.json, and the static frontend reads from that file.
